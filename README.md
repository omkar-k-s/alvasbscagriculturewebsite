# AIAST College Website

Modern, responsive website for **Alva's Institute of Allied Science & Technology (AIAST)**.

**🌐 Live:** https://www.aiast.org

## Overview

This website provides students, faculty, parents, and visitors with quick access to academic information, departments, events, news, placements, and contact details.

## Features

- Responsive design for mobile and desktop
- Department and course pages
- News and events
- Placement information
- Contact and enquiry pages

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui

## Run Locally

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
cd <PROJECT_FOLDER_NAME>
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
